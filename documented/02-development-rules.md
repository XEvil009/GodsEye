# GodsEye — Mandatory Development Rules

1. Every terminal command supplied must be Bash.
2. Document all project work.
3. Store project documentation in documented/.
4. Record every project-related installation, dependency,
   configuration change and required tool.
5. Provide only the command directly connected to the
   current development step.
6. Supply commands only when their purpose, prerequisites
   and expected result are understood.
7. Maintain continuity of commands, files, decisions,
   installations and project goals.
8. Prioritize actual source-code implementation.
9. Keep GitHub up to date with verified changes and
   synchronize GitLab and deployment through the approved process.
10. Document every future change request or modification,
    including its reason, using a Rule 10 change record.

No undocumented project changes.
