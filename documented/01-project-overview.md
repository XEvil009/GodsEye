# GodsEye — Project Overview

GodsEye is a consent-based live GPS location platform.

Owner: XEvil009
GitHub: https://github.com/XEvil009/GodsEye
GitLab owner: Xevilian
Deployment target: Vercel
Development environment: Android Termux

## Primary objectives
1. Mobile number validation and OTP verification.
2. Authorized Android device registration.
3. Explicit, revocable GPS location sharing.
4. Real-time location updates.
5. Authorized web dashboard and location history.

A phone number alone cannot reveal live GPS coordinates.
GPS must originate from an authorized device with explicit
location permission and active sharing consent.

Covert tracking and unauthorized surveillance are excluded.

Architecture baseline: Version 1.0 — FROZEN.
