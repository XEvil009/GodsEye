# Security Policy

- Never store OTP codes in plaintext.
- Never commit secrets or service credentials.
- Enforce device ownership server-side.
- Enforce viewer authorization for every location read.
- Require explicit and revocable location-sharing consent.
- Audit security-relevant events.
- Define location data retention and deletion.
- Display timestamps, accuracy and stale-location status.
- Follow current Android location permission requirements.
